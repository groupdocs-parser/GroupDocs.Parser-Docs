This section describes the advanced features of GroupDocs.Parser for Node.js via Java:

* [Loading](/parser/nodejs-java/loading/) - load documents from a local disk or a stream, specify the file format, open password-protected documents and control loading of external resources.
* [Using OCR to extract a text from images and PDFs](/parser/nodejs-java/using-ocr/) - extract a text from images and scanned PDFs with an OCR connector.
* [Working with ZIP archives and attachments](/parser/nodejs-java/working-with-zip-archives-and-attachments/) - iterate through container items and detect their file types.
* [Working with templates](/parser/nodejs-java/working-with-templates/) - define template fields, tables and barcodes to parse documents by a template.
* [Working with data extracted by template](/parser/nodejs-java/working-with-data-extracted-by-template/) - read fields and tables from the parsing result.
* [Extract data from databases](/parser/nodejs-java/extract-data-from-databases/) - extract tables from databases via JDBC.
* [Logging](/parser/nodejs-java/logging/) - receive errors, warnings and events with a logger implemented in JavaScript.
* [Working with text](/parser/nodejs-java/working-with-text/) - extract text in raw and accurate modes, search text, extract text areas, highlights, structure and formatted text.
* [Working with tables](/parser/nodejs-java/working-with-tables/) - extract tables from documents and pages.
* [Working with images](/parser/nodejs-java/working-with-images/) - extract images from documents, pages and page areas, and save them to files.
* [Working with barcodes](/parser/nodejs-java/working-with-barcodes/) - extract barcodes from documents, pages and page areas.
* [Working with hyperlinks](/parser/nodejs-java/working-with-hyperlinks/) - extract hyperlinks from documents, pages and page areas.
* [Generate previews](/parser/nodejs-java/generate-previews/) - render document pages to images.
* [Export Data](/parser/nodejs-java/export-data/) - export extracted data to XML files.
