GroupDocs.Parser provides API to extract a text from image files and non-text (scanned) PDF documents. GroupDocs.Parser doesn't contain an OCR engine: the recognition is performed by an OCR connector which integrates any paid or free OCR solution. The following articles describe how to use the API and how to create an OCR connector.
