**GroupDocs.Parser for Node.js via Java** is a document parsing API for Node.js. It extracts text, formatted text, metadata, images, tables, barcodes, hyperlinks, form fields, table of contents and structured data from PDF, Microsoft Office, OpenDocument, email, ebook, archive and other documents, and parses data by user-defined templates. The package wraps GroupDocs.Parser for Java, so it offers the same parsing engine and features.

GroupDocs.Parser supports [over 50 document formats](/parser/nodejs-java/supported-document-formats/) and does not require Microsoft Office or any other third-party software.
